# 反 AI 味儿设计规则

> 本文档是所有生成网站必须遵守的设计宪法。每条规则都有明确的"禁止"和"替代方案"。

## 一、AI 味儿的五大特征（必须规避）

| 特征 | 表现 | 根源 |
|------|------|------|
| 配色死板 | 蓝紫渐变用到吐 | Tailwind 默认主色调训练频率最高 |
| 布局死板 | Hero 大标题 + 三卡片并排 | 最常见 = 最不容易出错 |
| 字体死板 | 只用 Inter / Roboto | 训练数据中出现频率最高 |
| Emoji 泛滥 | 满屏 🐟🚀✨ 当图标 | AI 把 Emoji 当通用图标 |
| 内容空洞 | 无真实图片、文案刻板 | 求稳导致不敢个性化 |

## 二、绝对禁止项（❌）

### 配色禁止
- 紫色 / 靛蓝色 / 蓝紫渐变（#6366F1、#8B5CF6、#7C3AED）
- 纯平背景色（必须有噪点纹理、渐变或微妙图案）
- Tailwind 默认色板直接使用（必须自定义色值）
- 全站单一主色无层次（必须有主色 + 辅助色 + 点缀色）

### 布局禁止
- Hero + 三卡片并排的标准 SaaS 模板布局
- 完美居中对齐（必须有不对称元素打破平衡）
- 等宽多栏网格（必须有宽窄变化）
- 所有区块统一内边距（必须有呼吸节奏变化）

### 文案禁止
- 高深专业名词和无意义空话（"赋能""抓手""闭环"）
- Lorem Ipsum 占位文本
- 被动语态和超过 20 字的长句
- "提升生产力""卓越用户体验""高效协作"等套话

### 组件禁止
- Shadcn / Material UI 默认组件原样使用（必须深度定制样式）
- Emoji 作为功能图标（必须使用 SVG 图标库）
- 线性动画 ease-in-out（必须使用自定义缓动曲线）
- 所有按钮统一圆角（必须有圆角变化层次）

## 三、必须遵守项（✅）

### 文案风格
- 口语化，像朋友聊天
- 具体化，有数字和场景（"每天节省 2 小时"而非"提升效率"）
- 可以幽默、自嘲、甚至挑衅
- 每句话尽量不超过 15 个字
- 标题要有记忆点，避免"一站式解决方案"

### 图片系统
- 图标：使用 Iconify（20 万+ 矢量图标）
- 占位图：使用 Picsum Photos（URL 指定尺寸，真实照片）
- 真实图片：使用 Pexels 搜索
- 插画：使用 unDraw（可自定义颜色的 SVG 插画）
- 禁止使用 AI 生成的通用感插画

### 动效要求
- 页面加载必须有入场动画（非简单淡入）
- 滚动时必须有视差或元素揭示效果
- 交互元素（按钮、卡片）必须有 hover 微交互
- 动画缓动使用自定义 cubic-bezier，禁止 ease-in-out
- 动效要服务于内容，不为动而动

### 字体要求
- 标题使用有个性的展示字体（非 Inter/Roboto）
- 正文使用易读的无衬线或衬线字体
- 必须有字体大小层次（至少 4 个层级）
- 中英文混排时分别指定字体

## 四、差异化设计策略

参照网站分析后，必须在以下至少 3 个维度做出差异化：

1. **配色偏移**：提取参照网站主色后，偏移色相 15-30° 或调整饱和度
2. **布局重构**：参照网站是居中布局 → 改用左对齐 + 侧边栏
3. **字体替换**：参照网站用无衬线 → 改用衬线标题 + 无衬线正文
4. **动效风格**：参照网站是平滑过渡 → 改用弹性动效或步进动画
5. **装饰元素**：添加参照网站没有的装饰（网格背景、噪点、手绘线条）
6. **内容语气**：参照网站是正式商务 → 改用轻松幽默或犀利挑衅
