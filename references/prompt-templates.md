# 提示词模板库

> 可直接复用的提示词片段，根据项目需求组合使用。

## 一、角色设定模板

```
你是一位资深独立设计师兼前端工程师，专注于"反主流"的网页美学。
你鄙视千篇一律的 SaaS 模板，认为软件界面应该有触感和灵魂。

你的设计哲学：
- "现代但不要紫色" → 深灰+橙色 / 墨绿+米色 / 藏青+琥珀
- "极简但要有温度" → 大留白 + 手绘插画 + 暖色点缀
- "科技感但不要冰冷" → 深色背景 + 暖色高光 + 玻璃拟态
- "专业但不要无聊" → 不对称布局 + 意外动效 + 幽默文案

你不是在做标准答案，而是在做有个性的设计。
每一个像素都应该有理由。
```

## 二、反向提示（禁止清单）模板

```
设计禁止清单（违反任何一条都视为不合格）：

❌ 配色禁止
- 紫色/靛蓝色/蓝紫渐变（#6366F1、#8B5CF6）
- 纯平背景色（必须有噪点纹理或渐变）
- Tailwind 默认色板直接使用

❌ 布局禁止
- Hero + 三卡片并排布局
- 完美居中对齐
- 等宽多栏（必须不对称）
- 所有区块统一内边距

❌ 文案禁止
- 高深专业名词和无意义空话
- Lorem Ipsum 占位文本
- 被动语态和超过20字的长句
- "提升生产力""卓越体验""高效协作"等套话

❌ 组件禁止
- Shadcn/Material UI 默认组件原样使用
- Emoji 作为功能图标
- 线性动画 ease-in-out
- 所有按钮统一圆角
```

## 三、文案风格模板

```
网站文案必须做到：

1. 具体化：用数字和场景说话
   ✅ "每天节省 2 小时重复劳动"
   ❌ "大幅提升工作效率"

2. 口语化：像朋友聊天
   ✅ "用起来就像呼吸一样自然"
   ❌ "提供卓越的用户体验"

3. 带情绪：让用户有共鸣
   ✅ "再也不用在 10 个群里找文件了"
   ❌ "实现高效团队协作"

4. 可挑衅：打破第四面墙
   ✅ "别再假装你会看完那些 PPT 了"
   ❌ "助力企业数字化转型"

5. 标题要有记忆点
   ✅ "你的数据，不该住在 Excel 里"
   ❌ "一站式数据管理解决方案"

每句话尽量不超过 15 个字。
```

## 四、语境注入模板

```
先阅读以下内容，感受其中的情绪和氛围：

《[引用来源]》
[一段能传达目标氛围的文字 / 歌词 / 台词 / 诗句]

现在根据这种 [情绪关键词1]、[情绪关键词2] 的感觉来设计网站：
- 配色：[具体配色方向]
- 布局：[具体布局方向]
- 字体：[具体字体方向]
- 动效：[具体动效方向]
- 整体感觉：[描述目标氛围]
```

### 语境注入示例

**科技极客风：**
```
先阅读：《黑客与画家》— 编程语言是用来思考的工具
氛围：冷静、理性、沉思
→ 配色：深灰 #1a1a2e + 冷蓝 #0f3460 + 代码绿 #16c79a
→ 布局：左对齐，等宽字体标题，网格背景
→ 动效：打字机效果，代码雨背景
```

**复古怀旧风：**
```
先阅读：《午夜巴黎》— 我们都在逃避当下，怀念另一个时代
氛围：温暖、怀旧、文艺
→ 配色：米色 #f5f0e1 + 棕褐 #8b7355 + 暗红 #a64b4b
→ 布局：衬线字体大标题，杂志式分栏
→ 动效：纸张纹理，缓慢淡入
```

**赛博朋克风：**
```
先阅读：《神经漫游者》— 天空是电视调到空频道时的颜色
氛围：霓虹、颓废、未来感
→ 配色：黑色 #0d0d0d + 霓虹粉 #ff2a6d + 电光蓝 #05d9e8
→ 布局：故障艺术文字，倾斜元素，扫描线
→ 动效：glitch 效果，霓虹闪烁
```

## 五、参照网站分析模板

```
请分析以下参照网站，并提取设计要素：

参照网站：[URL]

请提取并输出：
1. 配色方案：主色、辅助色、背景色、文字色（含具体色值）
2. 字体方案：标题字体、正文字体、字号层级
3. 布局结构：页面区块划分、对齐方式、栅格系统
4. 动效风格：入场动画、交互反馈、滚动效果
5. 内容风格：文案语气、图片类型、装饰元素
6. 独特亮点：这个网站最出彩的 3 个设计细节

然后基于以上分析，给出差异化建议：
- 在哪些维度做改动可以避免直接抄袭？
- 推荐的替代配色/字体/布局是什么？
```
